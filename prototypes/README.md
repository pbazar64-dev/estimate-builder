## Дизайн-система

- **Тема:** светлая, зафиксированная (по требованию заказчика), в эстетике Vogue —
  журнальная типографика, воздух, тонкие hairline-линии, моно-акцент.
- **Палитра:** тёплая бумага `#FBFAF7`, чернила `#14110F`, hairline `#E6E1D8`;
  статусы приглушённые (олива/охра/оксблад).
- **Типографика:** дисплей — Playfair Display (дидон), интерфейс/таблицы —
  Helvetica-стек, табличные цифры.
- Данные на экранах — реальные (из смет/КП/договора «Ава Тетис»).

Прототипы иллюстративны и служат для утверждения визуального языка и состава
экранов до начала разработки.
