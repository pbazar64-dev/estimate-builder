# Estimate Builder — рабочее приложение (MVP)

Функциональное Node.js-приложение конструктора смет для Битрикс24. Реализовано
**без внешних зависимостей** (встроенный модуль `http`), чтобы деплой не зависел
от доступности npm-реестра. Слушает порт **3000** (требование платформы Vibecode).

> Расчёт **маржинальности не ведётся** (по требованию заказчика). Колонка
> «Трудозатраты Исполнителя» сохраняется как внутренние плановые часы.

## Что умеет

- **Реестр смет** — список, поиск, статусы, суммы, сводные плитки.
- **Мастер создания** — выбор страны/валюты → ставка часа подставляется и
  фиксируется.
- **Конструктор** — 3 уровня, этапы-чекбоксы, добавление из каталога,
  редактирование строк, **живой пересчёт** стоимости и итогов, автосохранение.
- **Карточка сметы** — инфоблок, версии, срок.
- **Версионирование** — сохранение версий-слепков с комментарием.
- **Каталог типовых работ** — 18 позиций из реальной сметы «Ава Тетис».
- **Настройки** — CRUD стран и ставок.
- **Генерация документов** — Excel/CSV (выгрузка), КП и Спецификация
  (печатные формы, клиентское представление без часов).

## Запуск локально

```bash
cd app
npm start          # или: node server.js
# → http://localhost:3000
```

## Структура

```
app/
├── server.js        # HTTP-сервер: статика + REST API (/api/*)
├── calc.js          # движок расчёта (формулы, итоги; без маржи)
├── seed.js          # стартовые данные (страны, каталог, демо-сметы)
├── package.json     # start: node server.js (нет зависимостей)
└── public/          # SPA: index.html, app.js, styles.css, playfair.woff2
```

## Деплой на Vibecode (платформа Битрикс24 Вайбкод)

Деплой идёт из **хранилища кода** приложения (не зависит от публичности репозитория).

```bash
APP_ID=966a4250-220a-4eb9-82b1-111ab336a35e      # приложение «Конструктор смет»
SERVER_ID=70231cf3-7f37-4b49-98f5-3b307187ce50   # сервер konstruktor-smet
API=https://vibecode.bitrix24.tech

# 1. Упаковать содержимое app/ (server.js в корне архива)
tar czf app.tar.gz -C app --exclude=data --exclude=node_modules .

# 2. Загрузить в хранилище кода → получить versionId
VER=$(curl -s -X POST "$API/v1/apps/$APP_ID/sources" \
  -H "X-Api-Key: $APP_KEY" -H "Content-Type: application/gzip" -H "X-Tags: manual" \
  --data-binary @app.tar.gz | python3 -c "import sys,json;print(json.load(sys.stdin)['data']['versionId'])")

# 3. Развернуть на сервере
curl -s -X POST "$API/v1/infra/servers/$SERVER_ID/deploy?stream=false" \
  -H "X-Api-Key: $APP_KEY" -H "Content-Type: application/json" \
  -d "{\"source\":{\"versionId\":\"$VER\"},\"runtime\":\"node20\",\"start\":\"node server.js\",\"port\":3000}"
```

Приложение будет доступно по адресу **https://app-b0f7edb57b61.vibecode.bitrix24.tech**.

> `APP_KEY` — секретный ключ приложения (`vibe_app_*`); в репозиторий не коммитится,
> передаётся через переменную окружения.
