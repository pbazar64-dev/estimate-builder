# 01. Продуктовая проработка (Product Discovery)

## 1.1. Пользовательские роли и сценарии

### Руководитель компании
- **Задачи:** контроль портфеля проектов, утверждение крупных/нестандартных
  смет, контроль сумм и статусов проектов, управление настройками системы (ставки,
  шаблоны, маршруты).
- **Боли:** нет сводной картины по суммам и статусам; не видит, где застряло
  согласование; узнаёт о «продали в минус» постфактум.
- **Сценарии:** открывает дашборд аналитики; заходит в смету на финальном
  согласовании; правит ставки по странам; проверяет шаблон договора.
- **Права:** полный доступ ко всему + настройки (см. `docs/03-access-model.md`).

### Руководитель проектов
- **Задачи:** создание и ведение смет, управление версиями, запуск и контроль
  согласований, генерация КП и договоров.
- **Боли:** ручная сборка сметы в Excel, потерянные версии, несоответствие
  оценок между проектами, долгие согласования в чатах.
- **Сценарии:** создаёт смету из сделки, наполняет из каталога, гоняет версии,
  запускает согласование, формирует договор из утверждённой версии.
- **Права:** полный доступ к сметам/версиям, генерация, аналитика; без
  системных настроек.

### Менеджер по продажам
- **Задачи:** быстро собрать КП под клиента, отправить, при согласии —
  сформировать договор; вести переговоры по версиям.
- **Боли:** каждый КП руками, легко ошибиться в цене/валюте, нет быстрой
  «пересборки» под другую страну.
- **Сценарии:** создаёт смету (выбор страны/валюты → ставка подставляется),
  наполняет из каталога, запускает согласование, генерирует КП/договор.
- **Права:** полный доступ к сметам, генерация, история; без системных настроек.

### Бизнес-аналитик
- **Задачи:** анализ данных по сметам, суммам, скорости согласования, типовым
  работам; подготовка отчётности.
- **Боли:** данные разрознены по Excel-файлам, нельзя агрегировать.
- **Сценарии:** просмотр реестра, версий, истории согласований, дашбордов —
  **только чтение**.
- **Права:** read-only на всё; без создания/редактирования/генерации/настроек.

## 1.2. User Journey — полный жизненный цикл сметы

```
[Лид/Сделка в CRM]
        │
        ▼
① Создание сметы из карточки сделки
   → мастер: выбор Страны + Валюты → автоподстановка Ставки часа
   → подтягиваются Компания, Контакт, Ответственный из сделки
        │
        ▼
② Конструктор сметы (черновик v1)
   → включение/отключение этапов (Моделирование, Настройка, ОПЭ активны;
     ППИ, Разработка — по желанию)
   → наполнение из Каталога типовых работ (1 клик) + ручные строки
   → drag-and-drop, изменение вложенности, копирование разделов
   → авто-пересчёт стоимости в реальном времени
        │
        ▼
③ Сохранение версии (v1, v2, …)
   → каждая версия = слепок (JSON) + сумма + валюта + ставка + комментарий
   → сравнение версий (diff) в переговорах
        │
        ▼
④ Запуск согласования (по маршруту)
   → задачи/уведомления согласующим (РП / Руководитель / Менеджер)
   → утвердить / отклонить / на доработку + комментарии
   → при отклонении — возврат автору, новый цикл версий
        │
        ▼
⑤ Статус «Согласована»
        │
        ├─▶ ⑥а Генерация КП (DOCX/PDF) → отправка клиенту
        │
        └─▶ ⑥б Генерация Договора + Спецификации (DOCX/PDF)
        │
        ▼
⑦ Подписание → статус «Подписан», отражение в сделке CRM
        │
        ▼
⑧ Архивация сметы (хранение версий, доступ на чтение, восстановление)
```

### Ключевые точки, где модуль убирает боль

| Этап | Было (сейчас) | Стало (модуль) |
|---|---|---|
| Сборка | Excel вручную | Конструктор + каталог, авто-пересчёт |
| Согласование | Чаты/звонки | Маршрут + уведомления + история |
| Версии | Копии файлов | Версионирование со слепками и diff |
| КП/договор | Копипаст вручную | Генерация из версии в 1 клик |
| Аналитика | Нет | Дашборды по суммам/статусам/срокам |
| Онбординг | Разбор чужих файлов | Каталог + шаблоны |

## 1.3. Продуктовые метрики успеха (KPI)

- ↓ Время сборки сметы: с часов до ≤ 20 мин.
- ↓ Время согласования: среднее ≤ 1 рабочий день.
- ↑ Доля смет, собранных из каталога (переиспользование) ≥ 80%.
- 0 расхождений между сметой, КП и договором (единый источник).
- 100% смет имеют привязку к сделке CRM.
