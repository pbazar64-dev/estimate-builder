# 04. UI/UX требования и дизайн-система

Интерфейс должен напоминать **профессиональную систему расчёта проектов**, а не
стандартные формы смарт-процессов Битрикс24. Отдельное приложение внутри
портала со своим UI.

## Продуктовые принципы UX

- **Скорость** — минимум кликов, горячие клавиши в редакторе (Enter — новая
  строка, Tab — вложенность, Ctrl+D — дублировать, Ctrl+S — сохранить версию).
- **Большие сметы** — плавная работа при 1000+ строк (виртуализация, дебаунс
  пересчёта).
- **Мгновенный пересчёт** — итоги обновляются на лету.
- **Работа с версиями** — переключение/сравнение в 1–2 клика.
- **Профессиональный вид** — вызывает доверие при показе клиенту.

## Дизайн-система «Vogue» (светлая тема)

Эстетика — журнальная: воздух, тонкие линии, крупная контрастная типографика,
сдержанная палитра, акцент через типографику и пространство, а не через цвет.

### Палитра (light)
```
--bg            #FBFAF8   /* тёплый белый фон, «бумага» */
--surface       #FFFFFF   /* карточки, таблицы */
--ink           #111111   /* основной текст, почти чёрный */
--ink-2         #55504B   /* вторичный текст */
--line          #E7E3DC   /* тонкие разделители */
--line-strong   #111111   /* акцентные линии (шапки, hairline под заголовком) */
--accent        #111111   /* моно-акцент (кнопки, актив) */
--accent-soft   #F1EDE6   /* фон hover/выделения */
--ok            #2E7D5B   /* согласовано */
--warn          #B08900   /* на согласовании / внимание */
--danger        #B23A3A   /* отклонено */
```
Тема — **светлая, фиксированная** (по требованию заказчика), в стиле Vogue.

### Типографика
- **Заголовки/крупные акценты:** высококонтрастный serif с «модным» рисунком
  (Playfair Display / Didot-подобный) — обложки экранов, названия смет, суммы.
- **Интерфейс/таблицы:** нейтральный гротеск (Inter / Helvetica-подобный),
  табличные цифры (`font-variant-numeric: tabular-nums`).
- Крупные числа сумм — serif, «журнальные».
- Заглавные разрядки (`letter-spacing`) для лейблов и рубрик (VOGUE-стиль
  «SECTION / 01»).

### Компоненты
- **Hairline-разделители** вместо тяжёлых бордеров и теней.
- **Таблица сметы:** зебра отсутствует; уровни различаются отступом,
  насыщенностью шрифта и нумерацией; итоги — жирный serif.
- **Статус-чипы:** капслок, тонкая рамка, без заливки (кроме акцентных).
- **Кнопки:** прямоугольные, моно-чёрные (primary) / контурные (secondary),
  капслок, разрядка.
- **Навигация:** левое меню-«оглавление» как рубрикатор журнала.

### Микро-взаимодействия
- Плавные переходы 150–200ms, без «резиновых» анимаций.
- Пересчёт — мягкая подсветка изменившейся суммы.
- Drag-and-drop строк — призрак строки + линия-вставка.

## Ключевые экраны (9)

1. Реестр смет
2. Карточка сметы (инфоблок + версии + график платежей)
3. Конструктор сметы (редактор)
4. Сравнение версий (diff)
5. Каталог типовых работ
6. Согласование (маршрут + история)
7. Мастер создания сметы (страна/валюта/ставка)
8. Настройки (страны/ставки, шаблоны, маршруты, этапы)
9. Виджет «Сметы» в карточке сделки CRM

Прототипы — `prototypes/index.html` и `prototypes/img/`.

## Встраивание в Битрикс24

- Приложение открывается **внутри портала** через `placement`:
  - `LEFT_MENU` / отдельная страница приложения — основной интерфейс;
  - `CRM_DEAL_DETAIL_TAB` или `CRM_DEAL_DETAIL_TOOLBAR` — виджет в сделке.
- Рендер в `<iframe>`; общий визуальный язык, но узнаваемо «профессиональнее»
  стандартного Битрикс24.
- Адаптивность: рабочий диапазон — десктоп (основной сценарий), корректная
  деградация на планшете.
