# 11. AI-функции (для будущего развития)

Опциональный слой поверх накопленных данных. Реализуется в Advanced и далее.
Рекомендуемый провайдер — Claude (Anthropic) API; строится как отдельный
AI-сервис с доступом к обезличенным историческим сметам.

## 11.1. AI-помощник по оценке работ
На основе истории похожих смет/услуг подсказывает трудозатраты (исполнитель/
клиент) и цену при добавлении позиции.
- Вход: название/описание услуги, контекст проекта, страна/ставка.
- Выход: рекомендованные часы + доверительный интервал + похожие прецеденты.
- Ценность: ускоряет оценку, снижает разброс между менеджерами.

## 11.2. Автоформирование сметы из описания проекта
Из текстового брифа/переписки генерирует черновик сметы (этапы, услуги из
каталога, оценки).
- Вход: описание задачи клиента.
- Выход: черновик с проставленными позициями каталога и часами (для правки).
- Ценность: старт сметы за минуты.

## 11.3. Рекомендации по маржинальности
Анализирует смету и предупреждает о низкой/отрицательной марже, предлагает
корректировки (часы, состав работ, ставка).
- Ценность: не «продать в минус».

## 11.4. Анализ изменений между версиями
Человекочитаемое резюме diff: «во v3 добавлен этап Разработка (+45 000),
сокращены интеграции (−2 позиции), маржа выросла на 4 п.п.».
- Ценность: быстрый разбор на согласовании.

## 11.5. Предсказание рисков
По признакам (большое число версий, долгие согласования, низкая маржа, частые
отклонения) прогнозирует риск срыва/убыточности сделки.
- Ценность: раннее вмешательство руководителя.

## 11.6. Технические принципы
- Обезличивание данных для обучающих выборок; RBAC и на AI-функции.
- AI даёт **рекомендации**, решение — за человеком (human-in-the-loop).
- Прозрачность: показывать основания рекомендации (прецеденты/факторы).
- Изоляция AI-сервиса; лимиты/кэш запросов; аудит AI-подсказок.
