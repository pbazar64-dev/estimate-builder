# 02. Функциональные требования

Обозначения: **[MVP]** — этап 1, **[P]** — Production Ready, **[A]** — Advanced.

---

## 2.1. Реестр смет (список) [MVP]

Главный экран — таблица всех смет. Колонки:

`ID · Название · Компания · Сделка · Ответственный · Дата создания · Дата
изменения · Текущая версия · Статус · Сумма · Валюта · Страна расчёта · Автор
последнего изменения`

Функционал:
- **Поиск** по всем полям (полнотекстовый по названию/компании/сделке).
- **Фильтры:** статус, ответственный, дата (диапазон), компания, сделка,
  страна/валюта.
- **Сортировка** по любому столбцу.
- **Быстрый просмотр** (side-panel без ухода со списка).
- **Архив:** архивирование и восстановление; отдельная вкладка «Архив».
- Массовые действия: архивировать, сменить ответственного (для ролей с правами).
- Пагинация/виртуализация под большие объёмы.

Статусы сметы (жизненный цикл):
`Черновик → На согласовании → Согласована → (Отклонена → Черновик) →
КП сформировано → Договор сформирован → Подписан → Архив`.

---

## 2.2. Карточка сметы [MVP]

### Информационный блок
`Название · Сделка (ссылка) · Компания (ссылка) · Контакт (ссылка) ·
Ответственный · Страна расчёта · Валюта · Ставка часа (из настроек, авто) ·
Статус · Текущая версия · Сумма · Маржинальность (авто) · Дата+автор
создания · Дата+автор изменения`.

### Блок версий
Список всех версий; по каждой: `Номер · Дата · Автор · Комментарий · Сумма`.

Действия над выбранной версией:
- Открыть (просмотр read-only);
- Сравнить с другой версией (diff);
- Скачать Excel;
- Сформировать КП;
- Сформировать договор (+ спецификацию);
- Отправить на согласование (**только для текущей версии**).

Блоки (доп.): график платежей, срок реализации, история согласований.

---

## 2.3. Конструктор сметы (редактор) [MVP]

Отдельный табличный интерфейс, похожий на профессиональный редактор смет
(не форма смарт-процесса).

### Этапы проекта (шапка)
- Строка этапов с чекбоксами включения.
- Активны по умолчанию: **Моделирование**, **Настройка штатного функционала**,
  **Введение в опытную эксплуатацию**.
- Дополнительно: **Предпроектное исследование**, **Разработка**.
- Действия: включить/выключить этап, изменить порядок (drag).
- При выключении этапа его строки скрываются и **не участвуют в расчётах**.

### Трёхуровневая иерархия
```
Уровень 1: Этап   (Настройка штатного функционала)
Уровень 2: Группа (CRM / Базовое)
Уровень 3: Услуга (Настройка воронок)
```
Уровень 2 может быть услугой напрямую под этапом (гибкая вложенность —
подтверждено исходной сметой).

### Колонки таблицы
`№₁ · №₂ · №₃ · Наименование · Описание · Количество · Трудозатраты Исполнителя
(ч) · Трудозатраты Клиенту (ч) · Цена за единицу · Стоимость`.

### Формулы (пересчёт мгновенный при любом изменении)
```
Цена за единицу = Ставка часа × Трудозатраты Клиенту
Стоимость       = Ставка часа × Трудозатраты Клиенту × Количество
Итог группы     = Σ стоимостей дочерних строк
Итог этапа      = Σ итогов групп/услуг
ИТОГО           = Σ итогов активных этапов
```
Себестоимость строки = `Ставка × Трудозатраты Исполнителя × Кол-во`;
маржа = `(Стоимость − Себестоимость) / Стоимость`.

### Возможности редактора
- Добавить / удалить / копировать строку;
- Копировать раздел целиком;
- Перемещать строки (drag-and-drop);
- Повышать/понижать уровень (изменение вложенности) с авто-перенумерацией;
- Массовое изменение значений (напр. ×коэффициент по выделению);
- Создание **шаблонов разделов** (сохранить выделенный раздел в каталог);
- Добавление позиций из **каталога типовых работ**;
- Сохранение черновика (autosave) и явное «Сохранить версию» с комментарием.
- Производительность: плавная работа при **1000+ строк** (виртуализация).

## 2.4. База типовых работ (каталог) [MVP]

Справочник для быстрого наполнения смет.

Поля позиции: `Название · Описание (шаблон) · Категория · Типовая оценка часов
(исполнитель / клиент) · Базовая ставка · Роль исполнителя по умолчанию`.

Функции:
- Фильтр по категориям, поиск;
- Добавление в смету в 1 клик (с учётом текущей ставки версии);
- Импорт каталога из существующего Excel «Ава Тетис» (стартовое наполнение);
- Редактирование каталога — **только администраторы/руководители**.

---

## 2.5. Версионирование [MVP]

Каждое сохранение версии создаёт запись. Хранится:
`Номер (автоинкремент) · Автор · Дата · Комментарий · Сумма · Валюта ·
Выбранная страна/ставка · Полный слепок сметы (JSON)`.

Реализовать:
- Просмотр истории;
- Откат к любой версии (создаёт новую версию-копию, историю не теряем);
- **Сравнение версий с подсветкой изменений (diff)**: добавленные/удалённые/
  изменённые строки, изменения сумм и часов;
- Комментарий при сохранении.

---

## 2.6. Согласование [P]

Запуск из карточки сметы по **настраиваемому маршруту**.

Согласующие (роли, настраиваемо): Руководитель проектов, Руководитель компании,
Менеджер по продажам.

Процесс:
1. Автор запускает согласование текущей версии.
2. Система создаёт задачу/БП для каждого согласующего (последовательно или
   параллельно — по маршруту).
3. Уведомления согласующим (Битрикс24 + модуль).
4. Каждый: **утвердить / отклонить / на доработку** + комментарий.
5. При отклонении смета возвращается автору с замечаниями (→ новая версия).
6. После всех утверждений → статус **«Согласована»**.

Фиксируется: комментарии, замечания, решения, полная история согласования
(кто/когда/что) с привязкой к версии.

---

## 2.7. Генерация документов [P]

Из выбранной версии генерируются:

- **КП** — подстановка: клиент, стоимость, этапы, перечень работ (клиентское
  представление, без часов), сроки, валюта, условия оплаты; статичные блоки
  «О компании»/«Наши клиенты»/«Контакты» из шаблона.
- **Договор** — реквизиты сторон (из CRM), стоимость по этапам, приложения,
  сроки, план-график платежей.
- **Спецификация** (приложение к договору) — детализированный перечень работ.

Требования: форматы **DOCX и PDF**, профессиональный дизайн, авто-нумерация
страниц, поддержка **загружаемых кастомных шаблонов** с переменными подстановки.

---

## 2.8. Выгрузка Excel [MVP]

Любая версия → Excel с сохранением: структуры уровней, группировок,
формул, итогов, валюты, профессионального форматирования (близко к исходному
шаблону «Ава Тетис»).

---

## 2.9. Связь с CRM [MVP/P]

Смета связана со **Сделкой (обязательно)**, Компанией, Контактом.

- Виджет «Сметы» в карточке сделки (placement) — список смет, статусы, суммы.
- Отображение статуса согласования в сделке.
- Быстрый переход к актуальной версии.
- Создание сметы из карточки сделки (с преднаполнением из сделки).

---

## 2.10. Аналитика и отчёты [P/A]

Дашборды:
- Кол-во смет по статусам;
- Средняя сумма сметы; средняя маржинальность;
- Кол-во версий на сделку;
- Скорость согласования (среднее время);
- Причины отклонения (топ);
- Самые частые услуги/работы;
- Динамика создания смет по месяцам.

---

## 2.11. Настройки приложения [MVP/P]

### Страны и ставки
`Название страны · Валюта · Стоимость часа`. Пример: Россия/RUB/3500,
Казахстан/KZT/25000, Беларусь/BYN/120, Узбекистан/UZS/450000. CRUD.

### Шаблоны документов
Загрузка шаблонов КП/договора/спецификации, настройка переменных подстановки.

### Маршруты согласования
Добавление/удаление ролей согласующих, порядок, тип (последовательно/параллельно).

### Этапы проекта
Добавление новых этапов, флаг «активен по умолчанию».

### Выбор ставки при создании сметы
Мастер создания: сначала выбор **Страны** и **Валюты** → авто-подстановка
ставки часа; все расчёты идут по выбранной ставке (фиксируется в версии).
