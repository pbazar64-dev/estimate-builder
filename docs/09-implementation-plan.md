# 09. План реализации

Оценка в человеко-днях (ЧД) для команды ~3–4 чел. (1 backend, 1–2 frontend,
0.5 QA, 0.5 PM/аналитик). Оценки — экспертные, уточняются после утверждения ТЗ.

---

## Этап 1 — MVP (4–6 недель)

**Цель:** собрать смету в конструкторе, версионировать, выгрузить Excel,
привязать к сделке. «Заменяем Excel».

**Функционал:**
- Каркас приложения B24 (OAuth, placement, сессии) — интеграция входа.
- Реестр смет (список, поиск, фильтры, сортировка, архив).
- Мастер создания (страна/валюта → ставка) + связь со сделкой.
- Конструктор сметы: 3 уровня, этапы-чекбоксы, формулы, мгновенный пересчёт,
  add/delete/move/reindent/copy, autosave.
- Каталог типовых работ (просмотр + вставка в смету) + импорт стартового Excel.
- Версионирование (сохранение слепка, список, просмотр, откат).
- Выгрузка Excel.
- Карточка сметы (инфоблок + версии).
- Ролевая модель (базовая, 4 роли) + аудит ядра.

**Трудоёмкость:** ~55–70 ЧД
(каркас/интеграция 10, реестр 6, мастер 4, конструктор 20, каталог 8,
версии 8, Excel 6, карточка 6, RBAC/аудит 6).

**Риски:** производительность редактора на 1000+ строк; точность Excel-выгрузки;
нюансы OAuth/placement облака.
**Зависимости:** доступ к тестовому порталу Битрикс24; стартовый каталог из Excel.

---

## Этап 2 — Production Ready (8–10 недель)

**Цель:** полный цикл до подписанного договора.

**Функционал:**
- Согласование (маршруты, задачи/уведомления B24, решения, история).
- Генерация КП (DOCX/PDF) по шаблону из реального КП «Ава Тетис».
- Генерация Договора + Спецификации (DOCX/PDF).
- Кастомные шаблоны документов + переменные (настройки).
- Сравнение версий (diff с подсветкой).
- Виджет «Сметы» в карточке сделки.
- Настройки: страны/ставки, этапы, маршруты, шаблоны.
- График платежей (модель + в документах).
- Аналитика v1 (статусы, ср. сумма, ср. маржа, скорость согласования).
- Полное покрытие RBAC + аудит; логирование/мониторинг.

**Трудоёмкость:** ~90–120 ЧД
(согласование 18, генерация КП 14, генерация договора+спец 16, шаблоны 10,
diff 10, виджет сделки 8, настройки 12, платежи 6, аналитика v1 12, аудит/секьюрити 8).

**Риски:** качество вёрстки DOCX/PDF под фирменный стиль; DOCX→PDF на сервере;
объём согласований и корнер-кейсы прав; синхронизация статуса в сделку.
**Зависимости:** финальные шаблоны КП/договора; регламент согласования; MVP.

---

## Этап 3 — Advanced (4–6 недель)

**Функционал:**
- Массовые операции и шаблоны разделов (создание/переиспользование).
- Расширенная аналитика/дашборды (причины отклонений, топ услуг, динамика,
  рентабельность по менеджерам/проектам).
- Исходящие вебхуки для внешних систем; задел под интеграцию с 1С.
- Оптимизация производительности (кэш, виртуализация, фоновые задачи).
- AI-функции v1 (см. `docs/11-ai-features.md`): помощник по оценке, анализ
  изменений версий, рекомендации по марже.
- Улучшения UX по результатам эксплуатации.

**Трудоёмкость:** ~55–75 ЧД
(массовые операции/шаблоны 12, аналитика v2 16, вебхуки/1С-задел 12,
перф-оптимизация 10, AI v1 15, UX-полировка 8).

**Риски:** качество AI-оценок (нужна история данных); сложность интеграции с 1С.
**Зависимости:** накопленные данные для AI; приоритеты бизнеса.
