# Estimate Builder — система управления сметами, КП и договорами для Битрикс24

Модуль для ООО **«Ава Тетис»** (интегратор Битрикс24), который превращает
ручной процесс подготовки смет / КП / договоров в единый цифровой конвейер
внутри корпоративного портала Битрикс24.

> **Статус:** проектная документация (ТЗ) + интерактивные прототипы UI.
> Написание кода начинается **после утверждения архитектуры** (см. раздел
> «Что дальше»).

---

## Что решает продукт

Сегодня сметы собираются вручную в Excel/Google Sheets, согласование идёт в
чатах и звонках, версии теряются, а КП и договоры каждый раз копируются
руками. Модуль **Estimate Builder**:

1. **Автоматизирует** сборку сметы от черновика до утверждённой версии;
2. **Стандартизирует** структуру смет, КП и договоров через шаблоны;
3. **Централизует** хранение и версионирование;
4. **Ускоряет** согласование за счёт маршрутов и уведомлений;
5. **Генерирует** КП, договор и спецификацию (DOCX/PDF) из утверждённой версии;
6. **Интегрируется** со сделками CRM Битрикс24;
7. **Даёт аналитику** по марже, скорости согласования и типовым работам.

## Основа проектирования — реальные документы «Ава Тетис»

ТЗ построено не на допущениях, а на трёх реальных документах компании,
которые полностью разобраны в [`docs/00-source-documents.md`](docs/00-source-documents.md):

| Документ | Что даёт для модели данных |
|---|---|
| **Смета (Excel)** — листы «Расчёты ППИ», «без разработки», «с разработкой», «Для КП» | Ставки по странам, 3-уровневая иерархия, формула стоимости, итоги по этапам, срок, платёжный календарь |
| **КП (PDF)** — «АО Конаково» | Структура коммерческого предложения: обложка, лицензии, разбивка по этапам (клиентское представление), условия оплаты, «О компании», контакты |
| **Договор/Спецификация (DOCX)** — № VB24-289 | Приложение = протокол согласования цен: стоимость по этапам, перечень услуг, план-график платежей, реквизиты сторон |

Ключевая находка: **смета → «Для КП» → КП** и **смета → Спецификация → Договор**
— это одна доменная сущность в разных представлениях. Именно она лежит в
центре модели данных.

**Подтверждённая на данных формула расчёта:**

```
Цена за единицу (для клиента) = Ставка часа × Трудозатраты Клиенту
Стоимость строки              = Ставка часа × Трудозатраты Клиенту × Количество
Итог этапа                    = Σ стоимостей строк этапа
Маржинальность                = (Σ Стоимость − Σ (Ставка × Трудозатраты Исполнителя × Кол-во)) / Σ Стоимость
```

## Рекомендуемая архитектура (кратко)

Портал у «Ава Тетис» — **облачный Битрикс24**, поэтому коробочные модули
недоступны. Из трёх рассмотренных вариантов (нативные смарт-процессы,
внешнее приложение, гибрид — подробное сравнение в
[`docs/05-architecture.md`](docs/05-architecture.md)) выбран:

### ✅ Внешнее приложение Битрикс24 (embedded SPA) с собственным бэкендом

- **Frontend:** React + TypeScript, встраивается в портал через
  `placement` (страница приложения + виджет в карточке сделки) в `<iframe>`.
  Даёт полностью кастомный «профессиональный» UI (таблица на 1000+ строк,
  мгновенный пересчёт, drag-and-drop) вне ограничений форм смарт-процессов.
- **Backend:** Node.js (NestJS) + PostgreSQL — собственная модель данных
  (сметы, версии-слепки JSONB, каталог, страны/ставки, история согласования).
- **Интеграция:** REST API Битрикс24 + вебхуки/события; авторизация через
  OAuth 2.0 приложения Битрикс24; данные CRM (сделка/компания/контакт)
  подтягиваются по API, документы генерируются на бэкенде.

Обоснование, критерии сравнения и схема развёртывания —
[`docs/05-architecture.md`](docs/05-architecture.md).

## Прототипы интерфейса

9 экранов в фирменной светлой теме в стиле **Vogue** (журнальная типографика,
воздух, тонкие линии): реестр смет, карточка сметы, конструктор сметы,
сравнение версий, каталог типовых работ, согласование, мастер создания,
настройки, виджет в карточке сделки CRM.

- Интерактивный прототип: [`prototypes/index.html`](prototypes/index.html)
- Статичные изображения экранов: [`prototypes/img/`](prototypes/img/)
